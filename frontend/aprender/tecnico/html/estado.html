Estado

Texto

Un estado representa la situación actual del entorno en un momento determinado. Contiene la información necesaria para que el agente inteligente pueda comprender el contexto en el que se encuentra y seleccionar la acción más adecuada.

Cada vez que el agente ejecuta una acción, el entorno puede cambiar, generando un nuevo estado que servirá como punto de partida para la siguiente decisión.
